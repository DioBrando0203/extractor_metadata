# Sistema visual y UX

El azul profundo comunica confianza y concentración; el azul claro organiza información sin fatiga. Verde sólo confirma procesamiento correcto, ámbar indica recuperación posible y rojo se reserva para error. Fondos neutros reducen ruido en lecturas largas.

Usar superficies claras, tipografía del sistema, radios de 6–14 px y sombra mínima. El token de texto secundario (`--muted: #52677d`) mantiene contraste AA sobre superficies claras; no reemplazarlo por grises más claros para contenido textual. Priorizar jerarquía: asunto, identidad del mensaje, alertas y propiedades. No copiar logos, nombre ni assets de Microsoft. La interfaz se inspira en el patrón de lector de correo, no lo suplanta.
